# GamerHack — مضيف جيلبريك PS4 بأقصى ثبات (v2)

مضيف جيلبريك لأجهزة **PlayStation 4** بواجهة عربية عصرية.
يكتشف الموقع إصدار النظام تلقائياً ويشغّل الثغرة المناسبة ثم يحمّل **GoldHEN**.

## الإصدارات المدعومة

| إصدار النظام | الثغرة المستخدمة | المجلد |
|---|---|---|
| 9.00 – 9.60 | PSFree + Lapse | `900/` |
| 10.00 – 11.02 | PSFree + Lapse | `css/` |
| 11.50 – 12.02 | Lapse (slopkit) | `slopkit/` |
| 12.50 – 13.00 | Poops (slopkit) | `slopkit/` |
| 13.02 – 13.52 | slopkit | `slopkit/` |

> الإصدارات الأخرى (مثل 11.03–11.50 و 12.02–12.50) لا توجد لها ثغرة عامة حالياً.

## طريقة الاستخدام

1. افتح الموقع من متصفح PS4.
2. أول زيارة: يُثبِّت الموقع ذاكرة التخزين المؤقت — انتظر حتى 100%.
3. افصل الشبكة، أغلق المتصفح، وأعد فتحه.
4. يبدأ الجيلبريك تلقائياً ويحمّل GoldHEN — يعمل بعدها **دون إنترنت**.

## الجديد في v2 — "أسطورة الثبات"

- ⚡ **أسرع**: صورة الخلفية مضغوطة (823KB → ~200KB) لتثبيت كاش أسرع وأقل عرضة للانقطاع.
- 🛡️ **أدق توجيه**: مقارنة الإصدارات بأرقام صحيحة بدل `parseFloat` — لا توجيه خاطئ أبداً.
- 🧠 **كشف حالة ذكي**: يراقب الواجهة رسالة الثغرة ويُميّز النجاح/الفشل (حتى مع الأنماط `inline` التي تستخدمها سكربتات GamerHack).
- ✅ **نجاح واضح**: توهج أخضر + خطوات "ما بعد GoldHEN" (تطبيق GoldHEN، إعدادات الديباج، Package Installer).
- ❌ **فشل عملي**: حدود حمراء + زر **إعادة المحاولة** + إرشاد لإعادة تشغيل الجهاز عند تكرار الفشل.
- ⏱️ **حارس زمني** في صفحات الكاش: إذا توقف التقدم دون اكتمال، تظهر مساعدة وزر إعادة محاولة بدل التعليق للأبد.
- 🔤 `<meta charset="utf-8">` لضمان ظهور العربية سليماً دائماً.
- 📊 شريط تقدم مرئي + زر إعادة محاولة عند خطأ التثبيت.

## ملاحظة للمطورين

- **لا تعدّل** ملفات الثغرات داخل `900/` و `css/` و `slopkit/` — أي تغيير قد يكسر سلسلة الاستغلال.
- سكربتات الثغرات تُحدّث الحالة عبر العنصر `#msgs` — يجب بقاؤه في `index.html`.
- `slopkit/jb.js` يُنشئ عنصرَي `#out` و `#state` للسجل، بينما `chain_lapse.js` يخفي `#out` بنمط inline — كلاهما مُعالَج في CSS.
- عند تعديل ملفات الواجهة لا حاجة لتحديث الـ manifests ما لم تُضف ملفات جديدة.

## الشكر والترخيص

- **PSFree** — رخصة AGPL-3.0 (المطور الأصلي: anonymous).
- **Lapse** — ثغرة kernel لأنظمة PS4.
- **GoldHEN** — بواسطة SiSTRo وفريقه.
- **slopkit** — سلاسل استغلال للإصدارات 11.50+.

هذا المشروع مجرد مضيف/واجهة؛ حقوق الثغرات والأدوات تعود لمطوريها الأصليين.
